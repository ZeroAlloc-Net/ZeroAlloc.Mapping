# ZeroAlloc.Mapping v1.4 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Promote three backlog items (B3 IQueryable projections, B6 cycle-safe mapping, B11 deep-clone mode) from `docs/backlog.md` into a v1.4 release of `ZeroAlloc.Mapping`. All three opt-in via new boolean properties on `MapAttribute<TSrc, TDst>`. Adds four new diagnostics ZAMP017–ZAMP020.

**Architecture:** All three features are properties on `[Map<TSrc, TDst>]` and emit additional members on the declaring class. Projection adds a static `Expression<Func<TSrc, TDst>>` property (new `ProjectionExpressionEmitter` helper, auto-inlines nested mappings). CycleSafe rewrites the standard `Map(src)` emit into a tracker-allocating entry + internal `Map(src, IDictionary<object, object> tracker)` recursive overload (extended `MapEmitter`). DeepClone walks the reachable-type graph at generator time and emits literal per-property clone code where no explicit nested `[Map<,>]` declaration takes over (new `DeepCloneEmitter` helper). Reuses existing `MapperDiscovery`, `MapperModel`, `MappingGenerator`; extends `Diagnostics.cs` with ZAMP017–ZAMP020.

**Tech Stack:** .NET 8/9/10 multi-target, Roslyn `Microsoft.CodeAnalysis.CSharp` 4.14, xUnit 2, Verify 28.

## Implementation order — rationale

Three features ship in dependency order:

- **Phase A (Tasks 1-2)** — Attribute properties + ZAMP017–ZAMP020 descriptors. Smallest blast radius; primes the model and diagnostic registry without changing any emit yet.
- **Phase B (Tasks 3-5)** — B3 Projection. Largest design surface (Expression-tree emit + nested-mapping inlining); ships first so the auto-inline groundwork is in place before B11's clone-walker reuses it.
- **Phase C (Tasks 6-7)** — B6 CycleSafe. Rewrites `Map(src)` body into an entry-helper pair when set; transitively enforces via ZAMP018.
- **Phase D (Tasks 8-9)** — B11 DeepClone. Reaches into the type graph; depends on the cycle infrastructure when type graphs cycle (ZAMP020 composes with CycleSafe).
- **Phase E (Tasks 10-11)** — Runtime + AOT smoke + allocation budgets.
- **Phase F (Tasks 12-13)** — Documentation + backlog cleanup + push + PR.

Total: 13 tasks. Modest split — each task is reviewable on its own and ships as a single commit.

```csharp
namespace ZeroAlloc.Mapping;

/// <summary>
/// Declares an infallible mapping from <typeparamref name="TSource"/> to <typeparamref name="TDestination"/>.
/// The generator emits a <c>static TDestination Map(TSource src)</c> method into the decorated
/// <c>static partial class</c>. Inner failures (smart-constructor exceptions, <c>Parse</c> exceptions,
/// nested-mapper exceptions) propagate uncaught. For a non-throwing path use
/// <see cref="TryMapAttribute{TSource, TDestination}"/>.
/// </summary>
[System.AttributeUsage(System.AttributeTargets.Class, AllowMultiple = true, Inherited = false)]
public sealed class MapAttribute<TSource, TDestination> : System.Attribute
{
    /// <summary>
    /// When <c>true</c>, the generator additionally emits a
    /// <c>public static System.Linq.Expressions.Expression&lt;System.Func&lt;TSource, TDestination&gt;&gt; Projection</c>
    /// property on the declaring class for use with EF Core's <c>IQueryable&lt;T&gt;.Select(...)</c>.
    /// Nested <c>[Map&lt;,&gt;]</c> declarations are auto-inlined into the expression tree (EF Core can't
    /// translate cross-mapper calls). Incompatible with <c>[MappingHook]</c>, <c>[MappingCulture]</c>,
    /// and <c>[PolymorphicMap]</c> — see <c>ZAMP017</c>.
    /// Default: <c>false</c>.
    /// </summary>
    public bool Projection { get; init; } = false;

    /// <summary>
    /// When <c>true</c>, the generator rewrites the standard <c>Map(src)</c> body into a tracker-allocating
    /// entry point that forwards to an <c>internal static TDestination Map(TSource src, IDictionary&lt;object, object&gt; tracker)</c>
    /// recursive helper. The tracker (keyed by reference equality) caches already-mapped destinations,
    /// breaking cycles via the cache. Every nested <c>[Map&lt;,&gt;]</c> reachable from a <c>CycleSafe = true</c>
    /// mapping must also declare <c>CycleSafe = true</c> — see <c>ZAMP018</c>.
    /// Default: <c>false</c>.
    /// </summary>
    public bool CycleSafe { get; init; } = false;

    /// <summary>
    /// When <c>true</c>, the generator walks the reachable-type graph at compile time and emits
    /// per-property literal clone code for every reference-typed property of <typeparamref name="TSource"/>
    /// where NO explicit nested <c>[Map&lt;,&gt;]</c> declaration exists. Explicit nested
    /// <c>[Map&lt;,&gt;]</c> declarations always win — they remain the family idiom.
    /// Uncloneable reachable types fire <c>ZAMP019</c>. Cyclic type graphs without <c>CycleSafe = true</c>
    /// fire <c>ZAMP020</c>.
    /// Default: <c>false</c>.
    /// </summary>
    public bool DeepClone { get; init; } = false;
}
```

```csharp
using Microsoft.CodeAnalysis;
using System.Text;

namespace ZeroAlloc.Mapping.Generator;

internal static class ProjectionExpressionEmitter
{
    /// <summary>
    /// Emits a static <c>Expression&lt;Func&lt;TSrc, TDst&gt;&gt; Projection</c> property body
    /// for the given <see cref="MappingDecl"/>. The expression literal assigns every destination
    /// property explicitly. Nested mappings are inlined transitively.
    /// </summary>
    public static void EmitProjection(
        StringBuilder sb,
        MappingDecl decl,
        PropertyMatch match,
        MapperClass cls,
        Compilation comp,
        INamedTypeSymbol srcType,
        INamedTypeSymbol dstType)
    {
        var srcFqn = decl.SourceTypeFqn;
        var dstFqn = decl.DestinationTypeFqn;

        sb.Append("    /// <summary>Mermaid stateDiagram-v2 representation of this state machine.</summary>\n");
        // NOTE: the above is a placeholder XML doc — replace with the correct projection-summary text.
        sb.Append("    /// <summary>LINQ expression-tree projection for use with IQueryable.Select.</summary>\n");
        sb.Append("    public static global::System.Linq.Expressions.Expression<global::System.Func<")
          .Append(srcFqn).Append(", ").Append(dstFqn).Append(">> Projection { get; } = ")
          .Append("__src => new ").Append(dstFqn).Append("\n    {\n");

        foreach (var pair in match.Pairs)   // PropertyMatch.Pairs is the (srcProperty, dstParameter) list
        {
            sb.Append("        ").Append(pair.DstName).Append(" = ");
            EmitExpressionFor(sb, pair, cls, comp);
            sb.Append(",\n");
        }

        sb.Append("    };\n\n");
    }

    private static void EmitExpressionFor(StringBuilder sb, PropertyPair pair, MapperClass cls, Compilation comp)
    {
        // Cases:
        //  1. Same-type direct member access:                  __src.Foo
        //  2. Flattened (B1 path like __src.Inner.Value):      __src.Inner.Value
        //  3. Nested [Map<,>] declared elsewhere:              new Dst { Field = __src.Field, ... }   (inlined!)
        //  4. Same-type collection (List<T>) with no explicit nested [Map<,>]:
        //         __src.Items   (EF Core handles trivial collection passthrough; for cross-type
        //                         collection projection the nested-mapping inlining recurses)
        //  5. Implicit/explicit numeric/string conversions:    EF Core handles via cast in SQL
        // Implement: walk the PropertyPair's resolved conversion path; for case 3 recurse via the
        // generator's already-collected nested-mapping discovery (NestedMappingResolver.cs).

        // ... emit per the cases above. See the v1.3 EmitMapMethod implementation in MapEmitter.cs
        // (lines ~60-220) for the existing conversion-path emit machinery; reuse the same path
        // resolution but produce expression-literal C# instead of imperative assignment.
    }
}
```

> The skeleton above intentionally elides the per-pair expression-emit detail; the implementer must adapt the existing `MapEmitter.EmitMapMethod` per-property emit logic into expression-literal form. The hardest case is case 3 (inlined nested mapping); use `NestedMappingResolver` to find the nested `MappingDecl` and recursively call `EmitProjection`-style emit at the property site.

In `MapEmitter.EmitMapMethod` (around lines 60-100), detect `decl.CycleSafe`:

```csharp
private static void EmitMapMethod(StringBuilder sb, MappingDecl decl, ...)
{
    if (decl.CycleSafe)
    {
        EmitCycleSafeMapPair(sb, decl, match, cls, comp, src, dst);
        return;
    }

    // ... existing v1.3 emit unchanged ...
}

private static void EmitCycleSafeMapPair(StringBuilder sb, MappingDecl decl, ...)
{
    var srcFqn = decl.SourceTypeFqn;
    var dstFqn = decl.DestinationTypeFqn;

    // Public entry: allocate tracker, forward to internal recursive overload.
    sb.Append("    public static ").Append(dstFqn).Append(" Map(").Append(srcFqn).Append(" src)\n");
    sb.Append("    {\n");
    sb.Append("        var __tracker = new global::System.Collections.Generic.Dictionary<object, object>(global::System.Collections.Generic.ReferenceEqualityComparer.Instance);\n");
    sb.Append("        return Map(src, __tracker);\n");
    sb.Append("    }\n\n");

    // Internal recursive overload: check cache, register destination BEFORE walking children, walk children.
    sb.Append("    internal static ").Append(dstFqn).Append(" Map(").Append(srcFqn).Append(" src, global::System.Collections.Generic.IDictionary<object, object> tracker)\n");
    sb.Append("    {\n");
    sb.Append("        if (tracker.TryGetValue(src, out var __cached)) return (").Append(dstFqn).Append(")__cached;\n");
    sb.Append("        var dst = new ").Append(dstFqn).Append("();\n");
    sb.Append("        tracker.Add(src, dst);\n");

    // Per-property assignments. For nested mappings, thread the tracker.
    foreach (var pair in match.Pairs)
    {
        sb.Append("        dst.").Append(pair.DstName).Append(" = ");
        EmitCycleSafePropertyAssignment(sb, pair, cls, comp);
        sb.Append(";\n");
    }

    sb.Append("        return dst;\n");
    sb.Append("    }\n\n");
}
```

> `EmitCycleSafePropertyAssignment` differs from the v1.3 single-line property emit in ONE respect: when the property mapping resolves to a nested mapping, it must thread `tracker` through (`CustomerMapper.Map(src.Customer, tracker)` instead of `CustomerMapper.Map(src.Customer)`). For other paths (member access, conversion, value-typed), the v1.3 emit is unchanged.

> **Constraint on `Dst`:** the cycle-safe emit assumes Dst has a public parameterless ctor. The dst-builder pattern is `var dst = new Dst(); dst.X = src.X; ...; return dst;`. Most v1.3 records (with init-only properties or primary constructors) DON'T have a parameterless ctor and use object-initializer syntax (`new Dst { X = src.X }`) or constructor-arg syntax. The CycleSafe emit cannot use object-initializer because the destination must be registered in the tracker BEFORE its children are walked (so a self-cycle resolves). If Dst has no parameterless ctor, fire a NEW diagnostic — `ZAMP021_CycleSafeUnsupportedDestinationShape` — pointing the user at "use a non-record type with a parameterless ctor for cycle-safe mapping." (Defer that diagnostic to a follow-up if it's not needed by the runtime test fixtures.)

> **Implementer note**: if extending the v1.3 emit infrastructure to thread the tracker turns out non-trivial, the simplest viable v1.4 cycle-safe shape is: only support cycle-safe on classes with parameterless ctor + settable properties (NOT records with init-only constructor args). Document this constraint in the design doc and add a diagnostic. The use case (ORM-traced aggregates with back-refs) almost always involves mutable classes anyway.

**Step 8.1: Create `DeepCloneEmitter.cs`**

```csharp
using Microsoft.CodeAnalysis;
using System.Text;

namespace ZeroAlloc.Mapping.Generator;

internal static class DeepCloneEmitter
{
    /// <summary>
    /// When invoked from <see cref="MapEmitter.EmitMapMethod"/> for a [Map(DeepClone = true)] decl,
    /// replaces the standard per-property emit with a literal clone for every reachable reference-typed
    /// property where no explicit nested [Map<,>] declaration exists.
    /// </summary>
    public static void EmitDeepClonePropertyAssignment(
        StringBuilder sb,
        PropertyPair pair,
        MapperClass cls,
        Compilation comp,
        HashSet<string> visited)   // type-FQN set to detect cycles at generator time
    {
        var propType = pair.SourceType;

        if (propType.IsValueType || propType.SpecialType == SpecialType.System_String)
        {
            // Bit-copy via standard assignment — no clone needed.
            sb.Append(pair.SrcAccessPath);
            return;
        }

        // Reference type. Has an explicit nested [Map<,>]?
        if (HasExplicitNestedMapping(cls, propType, pair.DestinationType))
        {
            // Use the standard nested-mapping emit (delegates to v1.3 path).
            sb.Append(/* CustomerMapper.Map(src.Customer) */ ...);
            return;
        }

        // Auto-clone case. Detect cycle.
        var typeFqn = propType.ToDisplayString(SymbolDisplayFormat.FullyQualifiedFormat);
        if (!visited.Add(typeFqn))
        {
            // Cycle in the type graph — caller should have fired ZAMP020 already.
            throw new InvalidOperationException($"Cycle in type graph: {typeFqn} (should have been caught by ZAMP020).");
        }

        if (IsCollection(propType, out var elementType))
        {
            EmitCollectionClone(sb, pair, elementType, cls, comp, visited);
        }
        else
        {
            EmitObjectClone(sb, pair, propType, cls, comp, visited);
        }

        visited.Remove(typeFqn);
    }

    // ... EmitCollectionClone, EmitObjectClone, IsCollection, HasExplicitNestedMapping ...
}
```

> Implementation detail: `EmitObjectClone` recurses through properties of the cloned type and emits `new T { P1 = src.P1, P2 = ..., ... }`. `EmitCollectionClone` emits `new List<T>(src.Items.Count); foreach (...) __dst.Add(new T { ... });` for `List<T>`, similar for arrays. Reuses the per-property recursion via `EmitDeepClonePropertyAssignment`.

**Step 8.2: ZAMP019 (uncloneable type) detection**

In `MappingGenerator.cs`, before emit, walk every `[Map(DeepClone=true)]` decl's reachable-type graph:

```csharp
foreach (var decl in cls.Mappings)
{
    if (!decl.DeepClone) continue;

    foreach (var typeFqn in WalkReachableReferenceTypes(decl, cls, comp))
    {
        if (HasExplicitNestedMapping(cls, typeFqn, ...)) continue;

        var typeSym = comp.GetTypeByMetadataName(typeFqn) ?? FindType(comp, typeFqn);
        if (typeSym is null) continue;

        if (!IsCloneable(typeSym))
        {
            ctx.ReportDiagnostic(Diagnostic.Create(
                Diagnostics.ZAMP019_DeepCloneUncloneableType,
                decl.Location,
                decl.SourceTypeFqn, decl.DestinationTypeFqn,
                typeFqn));
        }
    }
}
```

`IsCloneable(typeSym)`: returns true if the type has a public parameterless constructor AND every non-static field/property is either settable via `set`/`init` OR satisfied by a primary-constructor parameter. Returns false otherwise.

**Step 8.3: ZAMP020 (cyclic type graph without CycleSafe) detection**

Same walk, but track visited-types in a set. If the same type FQN appears twice during the walk, that's a cycle. If `decl.CycleSafe` is also true, this is fine (tracker handles it at runtime). If `decl.CycleSafe` is false, fire ZAMP020.

```csharp
if (CycleDetected(decl, cls, comp, out var cycleVia))
{

    {

            Diagnostics.ZAMP020_DeepCloneCyclicTypeGraph,
            decl.Location,
            decl.SourceTypeFqn, decl.DestinationTypeFqn,
            cycleVia));

}
```
